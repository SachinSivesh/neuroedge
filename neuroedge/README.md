# NeuroEdge

**An event-driven, self-calibrating EEG decoder on FPGA** (Zynq-7020 / ZedBoard).

A motor-imagery brain-computer interface: it decodes whether a person imagines
moving the LEFT or RIGHT hand from 8 EEG channels. Two ideas make it new:

1. **Event-driven covariance.** Each channel only sends a sample when it
   changes by more than an adaptive threshold. The covariance is updated only
   on these events and is *exact* for the reconstructed signal. This means far
   fewer multiply-accumulates than processing every sample.
2. **Drift-triggered, label-free self-calibration.** The encoder's own
   noise-floor tracker detects when the signal has drifted (new day, cap
   moved). This triggers an on-chip recalibration that uses no labels and no
   divider. The inverse matrix square root is computed with multiply-adds only
   (Newton–Schulz iterations).

Base paper we compare against: Malekmohammadi et al., Scientia Iranica 2019,
CSP + LDA on a Virtex-6 FPGA, 80.55% on BCI Competition IV-2a (2 classes).

## What is in this folder

```
python/                Python: experiments + bit-exact hardware model
  run_all.py           runs every step below in order
  test_model.py        self-test of the hardware model (no data needed)
  00_check_setup.py    packages + first EEG plot
  01_baseline.py       software CSP + LDA: the number to beat
  02_iir_design.py     8-30 Hz filter coefficients for the FPGA
  03_self_calibration.py   Newton-Schulz convergence + label-free alignment
  04_event_encoder.py  threshold sweep: work saved vs accuracy
  05_drift_recalibration.py  drift-triggered recalibration vs other policies
  06_hardware_model.py integer model for all subjects; writes RTL params + test vectors
  07_summary.py        all results in one table + headline figure
  08_demo_replay.py    live demo window (for the presentation)
  neuroedge/           shared code (config.py holds every number format)
rtl/                   Verilog: the hardware
  iir_bandpass.v       band-pass filter, 8 channels
  event_encoder.v      send-on-delta encoder with adaptive threshold
  event_cov.v          event-driven covariance
  drift_monitor.v      drift detector (uses the encoder's state)
  ns_calib.v           Newton-Schulz self-calibration unit
  backend.v            CSP features, log2, LDA decision
  neuroedge_top.v      everything connected
  params/              generated by Python: coefficients, trained weights
tb/                    self-checking testbenches (compare Verilog to Python)
sim/                   one-click simulation scripts (Vivado simulator)
vivado/                Vivado project + synthesis/power report scripts
vectors/               test vectors generated by Python
results/               every plot, CSV and report lands here
paper/                 paper draft goes here
```

**How the two halves fit together.** Python is the reference: `fixed.py` is
an integer model of every hardware block. Script 06 trains the decoder and
writes the trained weights into `rtl/params/` and test vectors into
`vectors/`. Each Verilog testbench feeds the same inputs to the hardware and
checks that it produces *exactly* the same integers as Python.

> The shipped `rtl/params/` and `vectors/` files come from synthetic toy data,
> so the Verilog can be simulated straight away. Running step 06 on real data
> replaces them.

## Part A: Python setup in PyCharm (each team member, ~20 min)

1. **Unzip** the folder somewhere with space, e.g. `D:\Projects\neuroedge`.
2. **Open in PyCharm:** File > Open > select the `neuroedge` folder > Trust Project.
3. **Create the virtual environment:** File > Settings (Ctrl+Alt+S) >
   Project: neuroedge > Python Interpreter > Add Interpreter >
   Add Local Interpreter > Virtualenv Environment > *New*.
   Base interpreter: **Python 3.11** if you have it (3.10–3.12 work).
   Click OK.
4. **Mark the code folder:** in the Project panel, right-click `python` >
   Mark Directory as > Sources Root (it turns blue).
5. **Install packages:** open the Terminal tab at the bottom (Alt+F12). Check
   that the prompt starts with `(.venv)` or `(venv)`, then run:
   ```
   pip install -r requirements.txt
   ```
6. **(Optional) choose where the EEG data goes.** By default it goes to
   `D:\neuroedge_data` (or `C:\Users\<you>\neuroedge_data` if there is no D:).
   It needs about 1.5 GB. To change it, set the environment variable
   `NEUROEDGE_DATA` to another folder.
7. **Self-test, no data needed:**
   ```
   cd python
   python test_model.py
   ```
   Expect `All model checks passed.`
8. **Quick full run on toy data** (about 3 min, checks everything works):
   ```
   python run_all.py --synthetic --subjects 1 2 3
   ```
   It should end with `All steps finished.` Synthetic numbers mean nothing;
   never report them.
9. **Real run, all 9 subjects:**
   ```
   python run_all.py
   ```
   The first run downloads BCI IV-2a (~1.3 GB) and takes about 15–25 minutes.
   Later runs reuse the cache in `results/cache`. If a step fails, fix the
   error and continue with `python run_all.py --from <step number>`.
10. **Pick the event threshold:** step 04 prints `Recommended K_DEFAULT = ...`.
    If it differs from `K_DEFAULT` in `python/neuroedge/config.py`, change it
    there and rerun from step 5: `python run_all.py --from 5`.
11. **Read the results:** `results/summary.md` (tables) and `results/summary.png`
    (headline figure). Every other plot is in `results/`.
12. **Demo window:** `python 08_demo_replay.py` (add `--speed 100` to go
    faster, or `--gif` to save `results/demo.gif`).

Tip: in PyCharm you can also right-click any script > Run. To pass options
such as `--synthetic`, use Run > Edit Configurations > Parameters.

## Part B: Vivado 2016 setup (on the laptop that has Vivado)

Do Part A step 9 first, so the Verilog parameters come from the real data.

### B1. Simulate the Verilog against Python (the main check)

1. Open **Command Prompt** (cmd, not PowerShell).
2. Go to the sim folder:
   ```
   cd /d D:\Projects\neuroedge\sim
   ```
3. If Vivado is not installed in `C:\Xilinx\Vivado\2016.4`, open
   `run_xsim.bat` in Notepad and correct the `VIVADO_DIR` line.
4. Run all five testbenches:
   ```
   run_all_tests.bat
   ```
   Expect five lines starting with `PASS`. `tb_top` streams 16 real trials
   through the whole core and takes a few minutes. Full logs are in
   `sim\log_tb_*.txt`.
5. To run one testbench and see its full output:
   `run_xsim.bat tb_top` (or `tb_iir`, `tb_encoder`, `tb_event_cov`, `tb_ns`).
6. To look at waveforms (for slides): after `run_xsim.bat tb_event_cov`, run
   `xsim tb_event_cov_sim -gui`, add signals to the wave window, then Run All.

| Testbench | What it proves |
|---|---|
| `tb_iir` | filter output equals Python on 8 channels |
| `tb_encoder` | every event decision equals Python |
| `tb_event_cov` | event-driven covariance, MAC count and event count equal Python |
| `tb_ns` | the five on-chip recalibrations (k and all 48 filter weights) equal Python |
| `tb_top` | decision, score, drift and recalibration flags for 16 trials equal Python |

### B2. Resource, timing and power reports (numbers for the paper)

1. Start menu > Xilinx Design Tools > **Vivado 2016.4 Tcl Shell**.
2. Run (use forward slashes):
   ```
   cd D:/Projects/neuroedge/vivado
   source build_reports.tcl
   ```
   This takes about 10–20 minutes. It ends by printing the timing slack at
   50 MHz, and writes `results/vivado_utilization.txt`,
   `results/vivado_timing.txt` and `results/vivado_power.txt`. The build is
   out-of-context, meaning the core is measured on its own, with no I/O pins.

### B3. Optional: GUI project (schematics, screenshots)

In Vivado, open the Tcl Console at the bottom and run:
```
cd D:/Projects/neuroedge/vivado
source create_project.tcl
```
Then use Flow Navigator > Run Synthesis > Open Synthesized Design > Schematic.

## Troubleshooting

- **`ModuleNotFoundError: neuroedge`**: the `python` folder is not marked as
  Sources Root, or you are not running from inside `python`.
- **MOABB/MNE asks a question or the download stops**: rerun; downloads
  resume. Check that the data folder has space.
- **`'xvlog' is not recognized`**: fix `VIVADO_DIR` in `sim/run_xsim.bat`.
- **A testbench prints FAIL**: send the log file (`sim/log_tb_*.txt`) and
  the first mismatch lines. The testbench shows exactly which value differs.
- **Changed `config.py`?** Rerun from step 6 so the Verilog parameters and
  vectors match: `python run_all.py --from 6`.
